# 2026-08-14 底栏源码动效对照与修正记录

## 源码对照

- 阅读 BiliPai 的 `FloatingBottomBar.kt`：确认底栏由基础层、选中前景层和独立移动指示器组成。
- 阅读 `DampedDragAnimation.kt`：确认槽位移动使用弹簧式状态变化，落位还包含压缩、速度形变和回弹。
- 阅读 `BottomBarChromeMotionSpec.kt` 与 `BottomBarMatchedLiquidChrome.kt`：确认底栏显隐、点击脉冲和 settle rebound 的时长/缓动关系。

## 已实施

- 新增 `AnimatedBottomNavigationView`，在现有 Material 菜单上绘制独立选中胶囊，使用 320ms 槽位移动和 260ms 落位回弹；保留菜单、点击、选中态和无障碍语义。
- 关闭 Material 内置 active indicator，避免两套选中背景叠加。
- 在 `MainActivity` 中补充底栏显隐的透明度和从底部轻微缩放动画，保留原有滚动位移行为；横屏 `NavigationRailView` 不变。

## 真机定位与修正

- 初次截图发现点击“关注”后胶囊视觉上停在“发现”。UI dump 同时确认 Material 的 selected 状态仍是“关注”。
- 日志和菜单层级定位到坐标换算错误：矩形先使用了子项的 `left/right`，随后又调用 `offsetDescendantRectToMyCoords`，造成第二项被重复平移。
- 修正为从子视图自身的 `(0, 0, width, height)` 开始换算；真机复测后胶囊准确位于“关注”。

## 第二轮视觉修正：清理背景并收紧内容

- 真机截图发现底栏内部有一块 Material 默认白色矩形；阅读 `NavigationBarView` 1.10.0 构造逻辑后确认，即使 XML 配置透明，Material 仍会注入默认 `MaterialShapeDrawable`。`AnimatedBottomNavigationView` 初始化时显式清除根背景，保留外层液态玻璃容器作为唯一背景层。
- 对照 BiliPai `FloatingBottomBarItem` 的垂直 `Column`，将图标从 28dp 收到 24dp、文字从 12sp 收到 11sp，并在 `onLayout` 中把 Material 的图标容器与标签组作为整体居中，目标间距为 1dp。
- 真机 UI dump 复测：图标容器 `[169,2149][241,2221]`、标签组 `[171,2224][239,2268]`，图标与文字间隔 3px；点击“关注”后胶囊和文字选中态正常。
