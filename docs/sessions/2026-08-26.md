# 2026-08-26 LiquidGlass 页面扩展会话

## 用户目标

在保持 XML/ViewBinding 架构的前提下，把适合的页面级区域改造成原生 LiquidGlass，并在真机上继续验证。当前没有迁移 Compose 的授权，也没有新增外部 AndroidLiquidGlass 运行时依赖。

## 实现摘要

- 扩展共享 LiquidGlassFrameLayout：主题色/透明度、RenderEffect 模糊、圆角、边框、高光、source 刷新、source 不可用 fallback，以及 attach/detach 清理。
- BasePager 的 pinned Toolbar、Tab/extraBar 使用共享玻璃层；Topic、App、CoolPic、Carousel、Follow 派生页复用共享页壳。
- User 只包裹稳定/折叠 Toolbar action；Feed 只包裹 Toolbar，sticky sort 保持普通不透明；Search 包裹 Toolbar，Message 已移出匿名只读范围。
- FAB、普通列表项、评论/回复、头像、封面、图片、加载/错误、Preference、WebView、BottomSheet 和 Dialog 保持普通渲染。
- 新增一个与应用主题和真实账号数据无关的 LiquidGlassFrameLayout instrumentation fixture，验证 XML inflation、前景控件语义和内部 backdrop 无障碍属性。

## 匿名范围与 Feed 回复可读性补充

用户进一步明确当前不保留登录功能，因此本次实现同步收紧为匿名只读：移除登录、消息、发帖、回复编辑、远程点赞/关注、举报和删除入口及其网络写入代码；保留服务端返回的评论/楼中楼清晰展示、排序、本地收藏/历史/黑名单/本地关注，以及只读富文本表情渲染。

Feed 详情的排序栏不再使用 `LiquidGlassFrameLayout`，也不再把 `RecyclerView` 作为 backdrop source；顶部 Toolbar 仍可使用玻璃层。这样避免 `RenderEffect` 采样回复列表后造成回复文字模糊。后续构建和自动化验证只覆盖匿名只读范围，不测试登录、发帖、回复编辑和消息路径。

本次清理单元已删除无入口的登录、消息、发帖/回复编辑、验证码、OSS 上传、@用户和 composer emoji 代码与资源；移除 `RecentAtUser`/`RecentEmoji` 专用 Room 数据库及迁移 fixture，保留 `StringEntity` 的搜索历史/黑名单用途和 `EmojiUtils` 的只读渲染用途。匿名 API 网络边界测试已去除 Account/Login 专用断言。清理可再生输出后，使用 Android Studio JDK 21 执行 `:app:assembleDebug`、`:app:assembleDebugAndroidTest`、`:app:testDebugUnitTest`（26 个）和 `:app:lintDebug` 均成功；定向 `LiquidGlassFrameLayoutInstrumentedTest` 在 PGEM10 上 1/1 成功。本单元未运行登录、发帖、回复编辑或消息测试。

定向真机测试结束后测试框架卸载了目标包；重新安装当前 `app-debug.apk` 后，`MainActivity` 冷启动返回 `Status: ok`、`LaunchState: COLD`，并保持在前台。该冷启动未进入任何登录、发布、回复编辑或消息路径。

## GitHub Releases 客户端更新续作

### 用户目标

为当前匿名只读 XML/ViewBinding 应用新增 GitHub Releases API 检测、APK 完整性校验、私有缓存下载和系统安装器流程；不恢复登录、发帖、回复编辑或其他远程写入。

### 实现

- 当时方案为设置页新增“检查本客户端更新”并暂时保留原有第三方应用更新入口；该批量更新入口已在 2026-08-27 的后续收敛中移除。
- 新增独立 GitHub Retrofit/OkHttp client，请求固定仓库 `godmiracle/Coolapk` 的 latest Release，不携带 Coolapk Cookie、Token 或 `X-App-*` 身份。
- 只接受非 draft/prerelease、semver tag、固定 GitHub Release 下载路径、安全 APK 文件名、100 MiB 内且带 `sha256:<64 hex>` digest 的资产。
- APK 流式写入 `cacheDir/updates/` 临时文件，完成大小/SHA-256 校验后由 FileProvider 生成 `content://` URI；Android 8+ 未授权时引导系统未知来源设置，不执行静默安装。
- 安装前检查包名和更高 `longVersionCode`，生产构建额外比较签名集合；Debug 页面明确提示正式 Release 签名不能通常覆盖 Debug 包。

### 验证与边界

- `:app:assembleDebug`、`:app:assembleDebugAndroidTest`、`:app:testDebugUnitTest`（33 个）和 `:app:lintDebug` 已通过；GitHub 请求 Header/Host、版本解析、资产筛选和 FileProvider/Intent 有测试覆盖。

- 本轮未执行登录、消息、发帖、回复编辑或其他已移出产品范围的测试。
