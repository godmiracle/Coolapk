# 2026-08-13 Code Review 优先问题实施记录

## 目标

退出 Explore 模式后，创建并实施 Rasen change `stabilize-core-data-network-and-lifecycle`，处理静态 Code Review 中最优先的五项问题。用户明确不要求登录流程；`X-App-Token` 继续保留，仅用于接口访问成功。

## 已实施

1. Room 数据迁移：修复 `FeedFavorite`、`HomeMenu`、`RecentAtUser` 的换表迁移，避免只删表不复制数据；补充历史 schema fixture 和迁移测试。
2. 凭证请求边界：从最终请求 URL 判断 HTTPS 和 Host，外部 `@Url`/跨 Host 重定向不携带 Token、Cookie、设备/应用身份 Header；API Host 行为保持不变。
3. 凭证备份策略：新增 `credentials.xml`，从旧 `settings.xml` 幂等迁移 API Token、会话和设备请求状态并清理旧键；普通 UI 偏好保留，云备份和设备迁移排除凭证文件。
4. WebView 生命周期：移除 `WebViewActivity.onDestroy()` 的 `exitProcess(0)`，保留 WebView 资源清理；通过独立 `:webview` 进程真实启动、返回、重开测试。
5. 网络语义：以 `suspendCancellableCoroutine` 桥接 Retrofit Call，取消时调用 `Call.cancel()`；非 2xx、必需空 body 和传输失败明确失败，取消异常继续传播；下载 302 仅保留显式 `Location` 场景。

## 本次液态玻璃界面落地

用户选择参考 BiliPai 的原生液态玻璃方向，并确认顶部不需要搜索，搜索保留为右下角动作按钮。本次在 XML/ViewBinding 架构内完成：

- 新增 `LiquidGlassFrameLayout`：应用最低基线为 Android 12 / API 31，直接使用 `RenderEffect` 模糊指定内容背景，不再保留 Android 7–11 半透明回退表面。
- 竖屏主导航改为三项玻璃底栏，并把搜索拆为右下角独立玻璃圆钮；横屏继续使用原 `NavigationRailView`。
- 首页 Tab/菜单外包玻璃容器，未增加顶部搜索或虚构业务标题。
- 保留既有 `HideBottomViewOnScrollBehavior` 和 RecyclerView 状态驱动的滚动中隐藏、停止后展示行为。

本次阶段性验证：XML 通过 `xmllint`，资源通过 `aapt2 compile`，自定义 View 通过 Android SDK 独立 Kotlin 编译。初次 Gradle 构建尝试被当前环境禁止本地 socket 创建（`FileLockContentionHandler`）拦截；后续已补做 APK 重建、安装、启动和真实设备视觉验收，详见下方回归记录。
