## 已确认结论

1. 项目是 Kotlin/Android 多模块工程，主模块是 `app`，另有 `mojito`、`GlideImageLoader`、`SketchImageViewLoader`。
2. 当前 UI ViewModel 的网络主链路是 Hilt `NetworkRepo`；`logic/network/Network.kt` 和 `Repository.kt` 是未发现 UI 调用的旧链路。
3. 本地数据由多个 Room 数据库和普通 `SharedPreferences` 保存。
4. 登录、Token、WebView Cookie、图片 OSS 上传、应用下载、已安装应用查询和外部深链均属于敏感或高风险边界。
5. GitHub Actions 构建 Release/Debug，但没有业务测试、lint 或真实设备验收。
6. 两套 Retrofit 配置中的 Base URL 常量没有尾部 `/`，初始阶段记录为高优先级待验证项；后续已统一修复并补充构造测试。

上述第 6 项是初始静态分析结论，后续处理已统一修复两套配置；本轮用户明确要求使用 Android Studio 当前 JDK/SDK，而不是额外安装 JDK 17/SDK 34。
